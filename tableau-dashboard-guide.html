ダッシュボードの作り方

2つ以上のシートを組み合わせ、見る人がデータを絞り込める作品にします。これまでのデータを使っても、新しく選んでも構いません。

  1. 問いと2つの見方を決める

    同じ問いに対して、役割の違うグラフを2つ考えます。例：「国ごとの豊かさと健康はどう関係するか？」を、散布図と地域別の棒グラフで見る。

    Gapminderの例：GDP × Life Expectancy の散布図と、region 別の平均寿命。自分のデータなら、カテゴリ別の比較と詳細のグラフなど。

  2. ワークシートを2つ以上つくる

    同じデータソースでシートをつくり、分かる名前を付けます。軸・単位・集計方法を確認しましょう。

    Gapminder：両方のシートの Year を同じ1年に絞る。散布図は Country を Detail に、region を Color に。棒グラフは region を Rows、AVG(Life Expectancy) を Columns に置きます。

  3. 新しいダッシュボードに配置する

    画面下の New Dashboard（新しいダッシュボード） をクリック。左の Size（サイズ） を Automatic（自動） にして、Sheets 一覧から2つのシートを白いキャンバスにドラッグします。Tiled（タイル） で並べると整えやすくなります。

    固定サイズなら例として1200 × 800。サイズは「Default（既定）」のレイアウトで設定します。「Desktop」は端末別レイアウトで、用紙サイズの選択ではありません。灰色の領域には配置できません。

  4. 漏斗アイコンでフィルターを付ける

    ダッシュボード内で、フィルターの入口にしたいシートを選択。右上付近の漏斗アイコンをクリックして Use as Filter（フィルターとして使用） を有効にします。見つからない場合は、シートのメニューから同じ項目を選びます。

    Gapminder：地域別の棒グラフをフィルターにする。Asia の棒をクリックすると、散布図にアジアの国だけが表示されます。

    薄くするだけの「ハイライト」とは異なります。フィルターは、選択に合わないデータを表示から除きます。

  5. 選択・解除をテストする

    別の棒もクリックして、もう一方のシートが変わることを確認。選択を解除すると全体に戻るかも試します。戻らない場合は Dashboard → Actions でフィルターアクションを編集し、Clearing the selection → Show all values を選びます。

    動かない場合：アクションの対象シートにもう一方のシートが含まれるか、両方が同じデータソースを使うかを確認。Gapminderの地域フィルターでは、散布図に region が含まれていることも確認します。

    タイトルと「棒をクリックすると絞り込めます」などの短い操作説明を添えます。

  6. 公開して、いつものフォームから提出する

    Server → Tableau Public → Save to Tableau Public で公開します（表示名はバージョンで異なります）。公開ページでダッシュボードを表示し、Share（共有） から作品URLをコピー。プライベートウィンドウでも、2つのシートとフィルターが使えるか確認してください。

    • リンク欄：Tableau Publicの作品URL。プロフィールURLではありません。
    • 画像：ダッシュボードのスクリーンショット1枚は必須。2枚目は任意で、絞り込み後の状態など。
    • 説明：問い・各シートの役割・フィルターの動作・発見と、データ・出典URL。

    公開前に個人情報や非公開データを除いてください。締切までは同じ宿題フォームから再提出できます。締切はWeek 4の宿題パネルに表示されます。

English instructions
  1. Choose a question and two related views. Use existing or new data.
  2. Create at least two worksheets from the same source. For Gapminder, filter both to the same single year: a GDP/life-expectancy scatterplot with Country on Detail and region on Color, plus a bar chart of average life expectancy by region.
  3. Create a New Dashboard. Set Size to Automatic in the Default layout, or choose a fixed size such as 1200 × 800. Drag both sheets into the white canvas using Tiled placement. The Desktop device layout is not the canvas-size setting.
  4. Select the regional bar chart in the dashboard and click its funnel icon, Use as Filter. The sheet menu offers the same command. Click Asia: the scatterplot should show only Asian countries.
  5. Test another selection and clear it. If necessary, edit Dashboard → Actions and set clearing the selection to Show all values. Check the target sheet and shared data source. Highlighting alone does not satisfy the filter requirement.
  6. Publish to Tableau Public. Verify the dashboard and filter while signed out. Submit the direct visualization URL, one required screenshot (a second is optional), and commentary explaining the question, each sheet, the filter, a finding, and the data/source URL. Resubmit through the usual homework form until the deadline shown in the agenda.
