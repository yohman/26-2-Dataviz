ポケモンデータの読み方

ポケモンは架空のゲームのキャラクターです。1行は1種の標準の姿で、1,025種を収録しています。ゲームの経験は必要ありません。
One row is one species’ default form. These are fictional game attributes, not measurements of real animals.

変数 / Variable意味 / Meaning扱い方 / Use

能力値はレベルや育成で変わる個体の値ではなく、種ごとの基礎値です。世代は初登場した世代で、能力値は元データ取得時点のものです。別の姿・メガシンカ等は含みません。
Base stats describe the species, not an individual at a particular level. Generation is when a species first appeared; stats are not historical values for that generation.

Tableauで画像を使う / Pokémon images in Tableau

  1. 更新したCSVをダウンロードしてTableauで開きます。既存の接続は新しいファイルを指定して更新します。
    Connect to the updated CSV, or point your existing connection to the new file and refresh.
  2. データペインの Image_URL を右クリックし、Image Role > URL（画像の役割 > URL）を選びます。不連続のディメンションとして扱います。
    Right-click the discrete dimension Image_URL and choose Image Role > URL.
  3. Image_URL、Name（または Name_Japanese）の順で Rows に置きます。まずは名前のフィルターでBulbasaur・Charmander・Eevee・Pikachu・Squirtleの5種を選びましょう。
    Place Image_URL, then the name on Rows. Filter Name to Bulbasaur, Charmander, Eevee, Pikachu and Squirtle.
  4. Attack を Columns に置き、集計を Average、マークを Bar にします。ラベルを表示します。Rowsの Image_URL を右クリックし、Sortを「Descending・Field・Attack・Average」に設定します。画像の列を広げ、行の境界をドラッグして高さを約80pxにすると画像が大きく見えます。表示は「Standard（標準）」で始めましょう。
    Place AVG(Attack) on Columns and select Bar marks. Show labels. Right-click Image_URL on Rows, then set Sort to Descending, Field, Attack, Average. Widen the image column and drag a row divider to roughly 80px high. Start with Standard view so fitting does not shrink the rows.

画像は行・列のヘッダーに表示されます。散布図の円が自動で画像に置き換わるわけではありません。大きなイラストに更新しました。Tableauは通常1項目あたり最大500画像、サーバー描画時は100画像までなので、全1,025種を一度に表示せず絞り込んでください。Image RoleはTableau 2022.4以降に対応します。TangelaとGolurkのみSVG画像なので、Tableau 2023.2以降が必要です。
Image Role displays images in row/column headers, not automatically as scatterplot marks. The URLs now point to larger artwork. Tableau typically supports up to 500 images per field, or 100 with server rendering. Filter the view rather than displaying all 1,025 at once. Image Role requires Tableau 2022.4 or later. Tangela and Golurk use SVG images and require Tableau 2023.2 or later.
